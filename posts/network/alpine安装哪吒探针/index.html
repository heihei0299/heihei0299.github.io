Alpine 安装哪吒探针#

适用场景：在 Alpine Linux（使用 OpenRC 初始化系统）上安装哪吒探针 Agent。你会学到如何下载对应架构的 Agent 可执行文件，并通过 /etc/init.d 脚本把它注册为开机自启服务。

获取官方教程与安装包#

官方教程：

https://nezha.wiki/guide/agent.html#在-其他-linux-如-alpine-使用-openrc-的发行版-安装-agent

手动安装需要下载对应版本的可执行文件：

https://github.com/naiba/nezha/releases

手动安装步骤#

解压文件到指定目录并赋予执行权限#

chmod +x nezha-agent

下载的压缩包需先解压，将 nezha-agent 二进制放到固定目录（如 /opt/nezha/agent/），并确保有执行权限。

创建开机自启任务#

vi /etc/init.d/nezha-agent

内容：

#!/sbin/openrc-run
name="nezha agent"

command="/opt/nezha/agent/nezha-agent" # 填写你解压出的文件对应的位置

command_background=true

command_args="-s servername:port -p token " # 修改server名，端口和token

pidfile="/run/${RC_SVCNAME}.pid"

depend() {

need net

use dns logger netmount

}

启动服务并加入开机自启#

chmod +x /etc/init.d/nezha-agent

rc-service nezha-agent start

rc-update add nezha-agent

验证与自查#

  1. rc-service nezha-agent status 显示 started
  2. pgrep -a nezha-agent 能看到 Agent 进程与启动参数（检查 -s 地址和 -p token 是否填对）
  3. 哪吒 Dashboard 面板中该服务器状态为在线
