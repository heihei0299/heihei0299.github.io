纯 IPv6 机器安装 Nezha Agent#

适用场景：只有 IPv6 地址的 VPS（无 IPv4）接入哪吒探针面板。本文记录从下载 Agent 到 systemd 托管的全流程，共五步。

1. 下载并安装 Agent#

wget https://github.com/nezhahq/agent/releases/download/v0.16.2/nezha-agent_linux_amd64.zip
mv nezha-agent /usr/local/bin/
chmod 744 /usr/local/bin/nezha-agent

下载的是 linux_amd64 架构包，其他架构请到 GitHub Releases 选择对应文件；纯 IPv6 机器需保证能访问 GitHub（必要时借助代理下载后上传）。

2. 测试启动#

nezha-agent -s <Dashboard服务器地址>:<端口> -p <连接密码>

如果面板中显示机器在线，说明测试成功。

注意：Dashboard 服务器地址需填写其可达地址（如 IPv6 地址或域名）；<连接密码> 为 Dashboard 中该服务器的连接密钥。

3. 配置 systemd 服务#

在 /usr/lib/systemd/system 下创建 nezha-agent.service：

vim /usr/lib/systemd/system/nezha-agent.service

内容如下：

[Unit]
Description=Nezha Agent
After=syslog.target

[Service]
Type=simple
User=root
Group=root
ExecStart=/usr/local/bin/nezha-agent -s <Dashboard服务器地址>:<端口> -p <连接密码>
Restart=always

[Install]
WantedBy=multi-user.target

4. 启动服务#

systemctl daemon-reload
systemctl enable nezha-agent
systemctl start nezha-agent

5. 查看状态#

systemctl status nezha-agent

验证与自查#

  1. systemctl status nezha-agent 显示 active（running）
  2. journalctl -u nezha-agent -e 无报错
  3. 哪吒 Dashboard 面板中该机器显示为在线，数据正常上报
