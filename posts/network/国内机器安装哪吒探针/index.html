国内机器安装哪吒探针#

适用场景：为境内 VPS 安装哪吒探针 Agent，接入自己的 Dashboard 面板统一监控。本文记录下载 Agent、上传、编写 systemd 服务与启动验证的完整流程。

1. 下载 Agent 并上传到国内机器#

下载地址：

https://github.com/nezhahq/agent/releases

mkdir /opt/nezha/agent

将文件上传到 /opt/nezha/agent，然后赋予执行权限：

chmod +x /opt/nezha/agent/nezha-agent

注意：GitHub Releases 下载在境内可能不稳定，可先下载再通过任意方式上传，或使用加速镜像。

2. 配置 systemd 服务#

vim /etc/systemd/system/nezha-agent.service

内容如下：

[Unit]
Description=哪吒探针监控端
ConditionFileIsExecutable=/opt/nezha/agent/nezha-agent

[Service]
StartLimitInterval=5
StartLimitBurst=10
ExecStart=/home/nezha/nezha-agent -s <Dashboard服务器地址>:<端口> -p <连接密码>
WorkingDirectory=/root
Restart=always
RestartSec=120
EnvironmentFile=-/etc/sysconfig/nezha-agent

[Install]
WantedBy=multi-user.target

请把 <Dashboard服务器地址>:<端口> 与 <连接密码> 替换为你的 Dashboard 信息（Dashboard 后台 → 服务器 → 安装命令中可查看）。 注意：ExecStart 中的 Agent 路径需与文件实际存放位置一致。上面保留了原文示例路径 /home/nezha/nezha-agent，如果你按第 1 步上传到 /opt/nezha/agent/，请同步修改 ExecStart 路径。

3. 启动服务#

systemctl daemon-reload
systemctl enable nezha-agent
systemctl start nezha-agent

验证与自查#

  1. systemctl status nezha-agent 显示 active（running）
  2. journalctl -u nezha-agent -e 无报错，能看到成功连接 Dashboard 的日志
  3. Dashboard 面板中该服务器状态为在线，能正常显示 CPU / 内存 / 流量数据
