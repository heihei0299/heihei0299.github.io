Windows 使用 Meta 内核#

适用场景：不依赖 GUI 客户端，在 Windows 上直接使用 Clash.Meta 内核（命令行启动），并用 Yacd 网页面板配合 IIS 进行可视化控制。本文按步骤记录完整流程。

1. 下载并解压 Meta 内核#

下载 meta 内核并解压缩：

//meta 内核下载地址
https://github.com/MetaCubeX/Clash.Meta/releases/download/v1.15.1/clash.meta-windows-amd64-v1.15.1.zip

为 meta 内核授予管理员权限。

在防火墙中放行 meta 内核（tun 模式下，参数 systack:system 需要此项）。

2. 准备 working 目录与规则数据#

在 meta 同目录下，创建名为 working 的目录。

下载 geosite.dat、geoip.dat、country.mmdb 文件：

//geoip.dat 下载地址
https://github.com/MetaCubeX/meta-rules-dat/releases/download/latest/geoip.dat

//geosite.dat 下载地址
https://github.com/MetaCubeX/meta-rules-dat/releases/download/latest/geosite.dat

//country.mmdb  下载地址
https://github.com/MetaCubeX/meta-rules-dat/releases/download/latest/country.mmdb

将 geosite.dat、geoip.dat、country.mmdb、config.yaml 放入 working 文件夹中。

💡 配置文件需要重新命名为 config.yaml

3. 命令行启动内核#

在 meta 内核所在文件夹的地址栏输入 cmd，调出 cmd 窗口：

cmd 中输入如下命令：

clash.meta.exe -d working

4. 配置 Yacd 面板#

下载 yacd 网页文件：

https://github.com/MetaCubeX/Yacd-meta/archive/refs/tags/v0.3.7.zip

在 working 文件夹下新建 dashboard 文件夹，将 yacd 网页文件（解压后）放入其中。

💡 config.yaml 中的参数 external-ui 必须为 external-ui: dashboard（存放 yacd 文件的相对目录）

启用 IIS 服务：启用IIS

为 yacd 网页文件授权：为网页文件授权

浏览器输入 127.0.0.1: port：

验证与自查#

  1. cmd 窗口内 clash.meta.exe 运行无报错，日志显示内核已启动
  2. 浏览器打开 127.0.0.1:<external-controller 端口> 能打开 Yacd 面板，并显示代理与节点列表
  3. 面板中能切换节点、看到实时流量，说明内核与面板连通
  4. 若使用 tun 模式，关闭代理后测试系统网络恢复正常（防火墙放行已生效）
